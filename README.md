# # Практична робота 10-11 — Варіант 1

> **Завдання:** Створити програму, яка після виклику `fork()` змінює значення глобальної змінної у батьківському процесі. Вивести значення змінної в обох процесах, щоб переконатися, що дані не спільні.

---

## Компіляція та запуск

```bash
gcc -Wall -Wextra -O0 fork_global.c -o fork_global
./fork_global
```

---

## Очікуваний вивід

```
=== До fork() ===
  PID=1234  global_counter=100  &global=0x601060

=== Дочірній процес (PID=1235, PPID=1234) ===
  global_counter до зміни  = 100
  &global (дочірній)        = 0x601060
  [дочірній] змін не вносимо
  global_counter після      = 100

=== Батьківський процес (PID=1234) ===
  global_counter до зміни  = 100
  &global (батьківський)    = 0x601060
  [батьківський] global_counter = 999
  global_counter після зміни = 999

=== Підсумок ===
  Батьківський: global_counter = 999
  Дочірній бачив:              = 100  (незмінено)
  Висновок: fork() копіює пам'ять — зміни незалежні!
  Хоча адреси однакові — це віртуальні адреси,
  які відображаються на різні фізичні сторінки (COW).
```

---

## Пояснення

### Чому адреси однакові, але значення різні?

```
До fork():
  Фізична сторінка A: global_counter = 100
  Віртуальна адреса 0x601060 → Фізична A

Після fork() (Copy-on-Write):
  Батьківський:  0x601060 → Фізична A (global = 100)
  Дочірній:      0x601060 → Фізична A (спільна, поки без змін)

Батьківський пише global = 999:
  Ядро копіює сторінку A → сторінка B
  Батьківський:  0x601060 → Фізична B (global = 999)
  Дочірній:      0x601060 → Фізична A (global = 100) ← незмінено
```

Обидва процеси бачать **однакову віртуальну адресу**, але після запису вона вказує на **різні фізичні сторінки** — це механізм **Copy-on-Write (COW)**.

---

## Що копіює fork()

| Ресурс | Копіюється? | Примітка |
|---|---|---|
| Глобальні змінні | ✅ (COW) | Незалежні після запису |
| Локальні змінні (стек) | ✅ (COW) | Незалежні після запису |
| Файлові дескриптори | ✅ | Спільна позиція у файлі |
| Потоки (threads) | ❌ | Тільки поточний потік |
| Сигнали (pending) | ❌ | Не успадковуються |
| PID | ❌ | Дочірній отримує новий |
