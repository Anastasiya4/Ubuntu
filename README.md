> **Дисципліна:** Системне програмування

---

## Мета роботи

Ознайомитися з процесом встановлення та запуску операційної системи Ubuntu Linux і налаштувати базове середовище для програмування мовами C/C++.

## Компіляція та запуск

### Базова компіляція
```bash
gcc -Wall -Wextra -O2 -lm tasks.c -o tasks
./tasks
```

### З підтримкою потоків (для завдань 1.4, 1.22)
```bash
gcc -Wall -Wextra -O2 -lm -pthread tasks.c -o tasks
./tasks
```

### З налагодженням
```bash
gcc -Wall -Wextra -g -O0 -lm tasks.c -o tasks_dbg
./tasks_dbg
```

### З оптимізацією O3
```bash
gcc -Wall -Wextra -O3 -lm tasks.c -o tasks_fast
time ./tasks_fast
```

## Приклади використання

### Завдання 1.6 — секунди
```
Введіть кількість секунд: 7322
7322 секунд еквівалентно 2 годинам 2 хвилинам 2 секундам.

Введіть кількість секунд: -3661
(у минулому) -3661 секунд еквівалентно 1 годинам 1 хвилинам 1 секундам.
```

### Завдання 1.7 — системи числення
```
Введіть основу: 8
Введіть число: 77
Значення 77 (основа 8) у десятковій системі = 63
```

### Завдання 1.9 — replace
```
Введіть рядок: The cat sat
Результат: "The-cat-sat", кількість замін: 2
```

### Завдання 1.21 — квадратне рівняння
```
Введіть a b c: 1 -3 2
Два дійсних корені:
  x1 = 2
  x2 = 1

Введіть a b c: 1 0 1
Комплексні корені:
  x1 = 0 + 1*i
  x2 = 0 - 1*i
```

## Основні команди Linux (довідка)

| Команда              | Призначення                          |
|----------------------|--------------------------------------|
| `ls -la`             | Список файлів з деталями             |
| `cd /шлях`           | Перехід до каталогу                  |
| `gcc file.c -o out`  | Компіляція                           |
| `./out`              | Запуск програми                      |
| `ldd ./out`          | Залежні бібліотеки                   |
| `nm -D /usr/lib/libm.so \| grep erf` | Пошук символу у бібліотеці |
| `valgrind ./out`     | Аналіз пам'яті                       |
| `gprof ./out gmon.out` | Профілювання продуктивності        |

## Встановлення середовища

```bash
# Оновлення системи
sudo apt update && sudo apt upgrade -y

# Встановлення інструментів
sudo apt install build-essential git clang valgrind -y

# Перевірка
gcc --version
clang --version
```
